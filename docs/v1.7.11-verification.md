## What changed

A CI wiring fix, and the closure of a divergence recorded by v1.7.10.

### Fixed — `duckdb` installed in `validate-json`

The job that runs `pytest tests/ -v` did not install `duckdb`. The
`tests/test_stores_200.py` module uses `pytest.importorskip` and
skipped at collection. The job now runs:

    - name: Install duckdb
      run: pip install duckdb --quiet

immediately before the pytest step. The main suite continues to
pass on machines that do not have the demo's dependencies, because
the module skips cleanly there; in CI, it runs.

### Fixed — trailing whitespace

Commit `82668a0` added ten spaces of trailing whitespace to the
blank line after the pytest step. Removed.

### The v1.7.10 divergence is closed

v1.7.10's CHANGELOG stated that the demo test runs in CI. It did
not: commit `82668a0` was titled *"Run stores-200 demo test in CI"*
and carried only a whitespace change to `.github/workflows/validate.yml`.

`docs/v1.7.10-verification.md` records the divergence and names two
reconciliation options from `RELEASE_PATTERN.md` invariant 8:

1. Follow-up release wires the demo test into CI.
2. Edit the v1.7.10 CHANGELOG section to remove the false line.

This release takes the first. The `v1.7.10` tag is immutable; its
CHANGELOG section is left as shipped. v1.7.11 makes the claim true.

## Known limits

### The demo test asserts strings the demo prints

It does not recompute them. What it catches: a changed count, a
dropped column, a broken join, a removed section, a change in the
demo's own words. A regression detector, not an oracle.

### Fixture coverage

The fixture symlinks the five registry Parquet files and `tools/`
as a directory into a tmp root. A new read from elsewhere in the
registry would still require a fixture change, and the failure
message (`FATAL: X not found: /tmp/.../X`) names the missing file.
The pattern across development has been that the fixture learns the
demo's reads by running into them.

### `stores.json` is written by `generate_facts.py` and committed

Byte-identical across runs today. If a future change makes the demo
non-deterministic in that file, the in-repo copy will drift.

### `facts.parquet` remains untracked after a manual run

A `.gitignore` entry is a separate one-line patch.
