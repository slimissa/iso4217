## What changed

The consumer surface: the Python wheel ships only the registry (no stale schema), CRLF is checked in CI, and 25 country-currency disagreements are classified (4 fixed, 21 documented with a reason). Two new gate checks (line endings, country-currency membership); no registry data change beyond AS/UM (USD) and AX/TF (EUR) gaining their `countries[]` entry. ADRs 0010 (Proposed), 0011 (Accepted), 0012 (Accepted) are committed.

### P5-01 — The wheel ships a valid registry
`wrappers/python/schema.json` was the v1.3.0 schema and gave 314 errors against the v1.4.0 registry beside it. Nothing read it, so nothing failed. The wheel and the sdist no longer ship a schema (ADR 0011). `tests/test_wheel_contents.py` builds the real wheel, installs it in a clean virtualenv, and validates the installed registry against the repository's schema; the same tests fail on the v1.9.1 packaging.

### P5-03 — Country-currency drift is detected
`check_country_codes.py` asked whether a country code resolves and never whether the currency agrees. Moving Germany to USD exited 0. `--membership` now compares both directions against the vendored ISO 3166 snapshot and the reviewed allow-list, and fails on a stale allow-list entry. 25 disagreements: 4 `fix-in-4217` (AS, UM → USD; AX, TF → EUR), 1 `fix-in-3166` (GS), 18 `allow-list-with-reason`, 2 `out-of-scope-historical` (CU, SV). ADR 0010 is Proposed until six rows (AS, UM, AX, TF, GS, XK) are confirmed against the ISO 4217 OBP page.

### P5-06 — Line endings are LF everywhere
`.gitattributes` pins `* text=auto eol=lf` plus explicit rules for `*.sh`, `*.py`, `*.json`, `*.sql`, and `*.parquet binary`. `tools/check_line_endings.py` fails on any CR byte in any text file and on a `.gitattributes` that drops the policy. Three Windows CI jobs run `check_line_endings.py`, `vendor_iso3166.py --check`, and `check_release_claims.py` with `core.autocrlf=true` forced.

### Release plumbing
The release pipeline now runs a 28-check gate (`check_country_codes.py --membership` and `check_line_endings.py` added). `windows-verify-manifest.txt` (v1.5.1 hashes, nothing read it) is deleted. `requirements-ci.txt` gains `setuptools>=68,<90`, `wheel>=0.42,<1`, and `build>=1.0,<2` so `tests/test_wheel_contents.py`'s real wheel build succeeds on CI.
