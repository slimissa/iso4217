## 8.4 — DuckDB typed query

**Q1:**
```
$ python3 -c "
import duckdb
r = duckdb.query(\"SELECT code FROM 'iso4217.parquet' WHERE is_independent AND minor_units = 3 ORDER BY code\").fetchall()
print([row[0] for row in r])
"
['IQD', 'LYD', 'TND']
```

**Q2:**
```
$ python3 -c "
import duckdb
r = duckdb.query(\"SELECT COUNT(*) FROM 'iso4217.parquet' WHERE pegged_to IS NOT NULL\").fetchone()
print(r[0])
"
46
```

**Q3:**
```
$ python3 -c "
import duckdb
r = duckdb.query(\"SELECT code, peg_rate FROM 'iso4217.parquet' WHERE peg_rate IS NOT NULL ORDER BY peg_rate DESC LIMIT 3\").fetchall()
print([(row[0], float(row[1])) for row in r])
"
[('XAF', 655.957), ('XOF', 655.957), ('KMF', 491.968)]
```

All three match the corrected values from `docs/v1.5.2-verification.md`'s
8.4 correction and the two lock-in tests in `tests/test_export_parquet.py`
(`test_independent_three_decimal_currencies`, `test_top_three_by_peg_rate`).
These values were not copied from that report — they were produced by
running the three queries above in this session.
