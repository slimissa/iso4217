Twelve claims for `1.7.1`, all passing against the release tree. The
manifest at `tools/release_claims.json` asserts:

- Version strings in VERSION, iso4217.json, CHANGELOG.md, README.md
- Version strings in the three wrapper manifests (Python, JS, Rust)
- Existence of the two new tools (`check_release_claims.py`,
  `release_claims.json`)
- Three expressions in `scripts/release.sh` that the shared
  document quotes: `check_no_orphan_variables`,
  `check_release_claims.py`, and `all workflows for`

The last three are operator-hygiene rule 6 in mechanical form — the
expressions the doc names are checked against the actual script.

The check runs in the release gate only, not in CI. See the reply to
ISO 3166 for the version-matching rationale.
