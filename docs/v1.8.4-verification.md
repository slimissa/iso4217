## What changed

Eleven items from the ISO 3166 and ISO 10383 review threads, plus four minor docs fixes. Tooling and documentation; no data change and no schema change.

### A10 — `docs/AUDIT.md`
Created the tool reachability audit. Every tool in `tools/` is now cataloged in categories (Producers, Validators, Enrichment) with columns for `--check`, CI, and Gate. It documents the rule 8 exceptions (manual, network-dependent enrichment tools). `RELEASE_PATTERN.md` rule 8 now links to this table.

### A11 — CURATED vs AGGREGATED
Added the rule to `RELEASE_PATTERN.md`: CURATED outputs compare bytes, AGGREGATED outputs compare content. Added an exception paragraph for `export_parquet.py` and `export_countries_parquet.py`, which use logical content comparison (`pq.read_table`) rather than bytes.

### A12 — Tag Verification
Updated `scripts/release.sh` to verify the tag message *before* pushing. The check is `$(...)` + `[[ ]]`, never `diff -q`. Added `[ -s "$msgfile" ]` to guard against empty messages and checked the exit code of `git tag -d` in case of a mismatch.

### A13 — `--cleanup=verbatim`
Aligned `scripts/release.sh` with the standard. Changed `git tag -a ... --cleanup=whitespace` to `--cleanup=verbatim`.

### A14 — Coordination Notes
Added a convention to `RELEASE_PATTERN.md`: if a release changes data that a sibling registry vendors, the CHANGELOG entry must name the sibling registries and state whether they need to re-vendor.

### H9a — Dependency Audits
Added `cargo audit`, `npm audit`, `pip-audit`, and `govulncheck` to the `validate-wrappers` CI job. Because no lockfiles are tracked, the job generates them on the fly (`cargo generate-lockfile`, `npm install --package-lock-only`) to audit the resolved graph.

### H9b — Rule 9
Added hygiene rule 9 to `RELEASE_PATTERN.md`: every lockfile is audited on every push. Sourced from the `zmij`/`syn 3.0.6` false alarm during the ISO 3166 review.

### Four minor docs fixes
- `docs/LAYERS.md`: updated ISO 3166 snapshot version (G1).
- `CONTRIBUTING.md`: updated "As of" version (G2).
- `README.md`: added `vendor_iso3166.py` to the tool tree (G3).
- `schema.json`: updated `meta.amendment_date` description to "PDF date" (G4).

## Known limits

- **No lockfiles are tracked.** Rule 9 says "every lockfile is audited," but `Cargo.lock` and `package-lock.json` are gitignored. H9a handles this by generating them in CI. A future change could commit them.
- **Go version bump.** The CI uses Go 1.27, meaning the Go wrapper is no longer tested against its declared minimum (`go 1.21`).
- **`check_amendments.py` and `check_release_claims.py` are not in CI.** They remain gate-only (or manual) by design.
- **`parse_source.py` runs nowhere.** Documented in `docs/AUDIT.md`, but no decision explains why.
