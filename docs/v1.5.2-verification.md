## 8.3 — pandas read

`pd.read_parquet('iso4217.parquet')` returns a DataFrame of shape
`(302, 11)`.

- `is_independent` dtype is `bool`
- `minor_units` dtype is `int8`
- `pegged_to` has 256 nulls (121 independent + 135 withdrawn)
- `peg_rate` has 258 nulls (256 + MAD basket + KWD undisclosed)

The 258-vs-256 difference is intentional. See
`docs/decisions/parquet-schema.md` for the null policy.

## 8.4 — DuckDB typed query

DuckDB reads the file natively. Typed queries work without casting:

    SELECT code FROM 'iso4217.parquet'
    WHERE is_independent AND minor_units = 3
    → ['JOD', 'OMR']

`WHERE pegged_to IS NOT NULL` returns 46. Top three by peg_rate:

    XAF  655.957
    XOF  655.957
    DJF  177.721

This is the reason the Parquet export exists — a consumer can filter
on a native boolean and a native integer, and use `IS NOT NULL` as an
actual null check rather than a string comparison.

## 8.7 — Windows Parquet check

Deferred to a Windows environment. The Parquet format is binary, so
the BOM and CRLF concerns that motivated the v1.5.1 Windows checks do
not apply. The check is narrower:

1. Clone the repository at tag `v1.5.2` on Windows.
2. `pip install pyarrow`
3. `python3 tools/export_parquet.py --check` — should exit 0.
4. `certutil -hashfile iso4217.parquet SHA256` — compare against the
   Linux value recorded in `windows-verify-manifest.txt` (or the
   manifest from `/tmp/v152-parquet-manifest.txt`).

The Linux-side Parquet SHA-256 and byte size are recorded in the
verification manifest. When the Windows check completes, a follow-up
commit will append the result to this section.

## Known remaining gaps

- The Parquet writer uses pyarrow defaults for compression (snappy)
  and row-group sizing (single group). At 302 rows this is correct;
  multiple row groups become relevant above ~100,000 rows.
- The `standard` field on every JSON entry is deferred to v1.6.0, per
  `docs/decisions/v1.6.0-candidates.md`.
- Packages are not yet published to PyPI, npm, or crates.io. Users
  install from source or from the git tag.
