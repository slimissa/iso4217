## What changed

Five input-hardening items, and one documentation fix. No data changes, no schema changes.

### F11 — A missing schema layer no longer passes silently
`validate.py` previously passed (exit 0) if `schema.json` was missing. The warning it tried to emit was swallowed by `validate()` rebuilding `result.warnings` at the end of its run. The validator now exits 2 when the schema file is missing, and exits 3 when the `jsonschema` package itself is absent (rule 7: a check that cannot run must fail).

### F10 — Hostile input exits 2, never a traceback
Deep nesting (`RecursionError`), huge integers (`ValueError`), invalid UTF-8 (`UnicodeDecodeError`), and non-object roots (`AttributeError`) are now caught at the loader boundary and exit 2 with a message naming the file.

### F12 — Strict JSON
The loader rejects duplicate keys (last-value-wins is a bug, not a feature), `NaN`, `Infinity`, and floats that overflow to infinity (`1e999`).

### F21 — Snapshot SHA-256
`tools/vendor_iso3166.py` now records the snapshot's SHA-256 in `tools/iso3166_snapshot.meta.json`. `--check` verifies this hash before making any network call, so a hand-edited snapshot fails even offline.

### F26 — Docstring
`check_readme_drift.py` now documents that it requires a git work tree (it uses `git ls-files`), and explains what the `git add -A` rule depends on.

## Known limits

- **Root-shape mismatch beyond the four named classes.** A JSON root that is an object but has the wrong shape below it (e.g. `"currencies": []`) still reaches the domain validators and exits 1 with `AttributeError`. F10 was scoped to loader-level hardening; stopping after schema errors is a separate change.
- **Other loaders are unhardened.** F10 named `validate.py` only. The exporters and `update_from_iso.py` have their own `load_registry` and were not touched.
- **`CONTRIBUTING.md` "As of v1.8.4"** remains stale. It is untouched by this release by design (D7).
- **Rule 7's list of instances** in `RELEASE_PATTERN.md` does not cite F11. The scope excluded pattern-document changes.
