## What changed since v1.6.2

**Tooling:**
- `tools/check_snapshot_freshness.py` — adopted from ISO 3166 v1.6.1.
  Scoped to `tools/*_snapshot.json`; reads sibling
  `<stem>.meta.json` when present, falls back to the snapshot's own
  `meta` block.
- `tools/check_registry_freshness.py` — the registry's own freshness
  check, restored as a distinct tool under a name that describes
  its purpose. Reads `iso4217.json → meta.updated`, 180-day
  threshold.
- `tools/iso3166_snapshot.meta.json` — `review_by` and
  `refresh_cadence` moved under a `meta` object to match the shape
  the adopted tool reads.

**CI:**
- `check-snapshot-freshness` — runs the snapshot tool.
- `check-registry-freshness` — runs the registry tool.

**Release script:**
- The gate now runs both freshness checks.
