## What changed since v1.7.6

**Added:**
- `tests/test_check_registry_freshness.py` — 18 tests covering the
  `--today` flag, the one-day timezone tolerance, the threshold
  flag, the fatal paths, the `--json` output, and one assertion
  against the committed registry.
- `tests/test_check_snapshot_freshness.py` — 8 tests covering the
  three-state design (`ISO date` / `"closed"` / `null`), the
  sibling-metadata preference, and the no-snapshots fatal case.

**Fixed:**
- `tools/check_registry_freshness.py` — an invalid `--today`
  value previously raised an uncaught `ValueError`. It now returns
  `EXIT_FATAL` with a diagnostic message. Found by the new test
  suite before the release attempt that would have shipped the bug.

## Post-release note

The `## [1.7.7]` section of `CHANGELOG.md` was amended on
2026-10-07 (commit `b2bc697`) to add a `### Fixed` subsection
describing the `--today` ValueError fix. The amendment landed
after the tag `v1.7.7` (commit `c34ad8b`) was created.

Per `RELEASE_PATTERN.md` invariant 8, the tag is immutable. The
divergence between the CHANGELOG at the tag and the CHANGELOG on
`main` is the correct reconciliation: the tag records what shipped;
the CHANGELOG records what is known.
